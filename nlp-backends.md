# UnifiedNLP Backends

The idea of using [UnifiedNLP](https://github.com/microg/UnifiedNlp) backends to get location was perceived from [microG](https://github.com/microg/GmsCore). But microG is no more using the UnifiedNLP backends, as the [installation page](https://github.com/microg/GmsCore/wiki/Installation/3a79240fc46494bbbebc3c16ac033d2e889e83ec) states:

> You can safely uninstall microG DroidGuard Helper and all UnifiedNlp backends if you installed them before, since now everything is integrated inside microG Services.

They have removed the backends page from their wiki. Following is the list of NLP (Network Location Provider) backend apps copied from their [last revision](https://github.com/microg/UnifiedNlp/wiki/Backends/69f9d6c0f37597103c61cd964da1d888329ed1b5). Most of these are available on [F-Droid](https://search.f-droid.org/?q=unifiednlp).

MyLocation talks to these backends through [UnifiedNLP API](https://github.com/microg/android_external_UnifiedNlpApi). Backends are free to fetch location using any of the methods meant to be used by [Network Location Providers](https://developer.android.com/reference/android/location/LocationManager#NETWORK_PROVIDER) e.g. Wi-Fi, Bluetooth, cellular network etc. Usually these backends connect to a database service on internet.

---

### AMap UnifiedNlp Backend | [IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/com.gitlab.fasheng.nlp.amap) | [GitLab](https://gitlab.com/fasheng/amap-nlp-backend)
Uses the AMap Location API (a popular location service in China) to resolve locations. The database is proprietary.

### AppleWifiNlpBackend | [F-Droid](https://f-droid.org/packages/org.microg.nlp.backend.apple) | [GitHub](https://github.com/microg/AppleWifiNlpBackend)
Uses Apple's service to resolve Wi-Fi locations. It has excellent coverage but the database is proprietary.

### Baidu UnifiedNlp Backend | [IzzyOnDroid](https://apt.izzysoft.de/fdroid/index/apk/com.gitlab.fasheng.nlp.baidu) | [GitLab](https://gitlab.com/fasheng/baidu-nlp-backend)
Uses the Baidu Location API (another popular location service in China) to resolve locations. The database is proprietary. 

### Déjà Vu Location Service | [F-Droid](https://f-droid.org/packages/org.fitchfamily.android.dejavu) | [GitHub](https://github.com/n76/DejaVu)
Uses locally acquired WLAN/WiFi AP and mobile/cellular tower data to resolve user location.

### LocalGSMBackend | [F-Droid](https://f-droid.org/packages/org.fitchfamily.android.gsmlocation) | [GitHub](https://gitlab.com/deveee/Local-GSM-Backend)
Local location provider for GSM cells. It works offline by downloading freely licensed database files from Mozilla, OpenCellID, or lacells.db.

### LocalGSMLocationProvider | *Last update: 2014* | [F-Droid](https://f-droid.org/packages/org.gfd.gsmlocation) | [GitHub](https://github.com/rtreffer/LocalGSMLocationProvider)
Local opencellid based location provider backend. Has been surpassed by LocalGSMBackend which also has an OpenCellID option

### Local NLP Backend - A Déjà Vu Fork | [F-Droid](https://f-droid.org/packages/helium314.localbackend) | [GitHub](https://github.com/Helium314/Local-NLP-Backend)
Fork of the Déjà Vu NLP Backend with some improvements and some crude UI for configuration and importing / exporting data.

### LocalWifiNlpBackend | [F-Droid](https://f-droid.org/packages/org.fitchfamily.android.wifi_backend) | [GitHub](https://github.com/n76/wifi_backend)
Local location provider for Wi-Fi APs using on-phone generated database.

### Merged WiFi UnifiedNlp Backend - | [F-Droid](https://f-droid.org/packages/info.spotcomms.wlanbackend) | [GitHub](https://github.com/Divested-Mobile/WLANBackend) | [GitLab](https://gitlab.com/divested-mobile/wlanbackend)
Uses a CSV database generated by [WiFiDatabaseMerger](https://gitlab.com/divested-mobile/wifidatabasemerger) to provide location.

### MozillaNlpBackend | [F-Droid](https://f-droid.org/packages/org.microg.nlp.backend.ichnaea) | [GitHub](https://github.com/microg/IchnaeaNlpBackend)
Uses the Mozilla Location Service to resolve user location. The coverage is OK. Only the cell tower database is free.

### OpenWlanMapNlpBackend | *Last updated: 2015* | [GitHub](https://github.com/microg/OpenWlanMapNlpBackend)
Uses OpenWlanMap.org to resolve user location but the NLP backend did not reach release-quality, yet. Users interested in a freely licensed and downloadable database for offline use should stick with Radiocells for now.

### Radiocells.org UnifiedNlp Backend | [F-Droid](https://f-droid.org/packages/org.openbmap.unifiedNlp) | [GitHub](https://github.com/wish7code/org.openbmap.unifiedNlpProvider)
Uses [Radiocells.org](https://radiocells.org/) to resolve user location. Community-created, freely licensed database that can optionally be downloaded for offline operation. The coverage [varies from country to country](https://radiocells.org/stats/countries) (it's best in central Europe).

### Trains UnifiedNLP | [F-Droid](https://f-droid.org/packages/de.sorunome.unifiednlp.trains) | [GitLab](https://gitlab.com/Sorunome/trains-unifiednlp)
Detects if you are connected to a trains wifi (Europe, but not all networks are supported) and, if so, provides the location data provided by the train to your android phone.
